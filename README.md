# Bili Music

使用 Flutter 开发的，以 BiliBili 为音频源的音乐播放器。

![demo](doc/demo.png)

## 功能

- [x] 媒体搜索
- [x] 音乐播放
- [x] LLM提取歌曲信息（符合OpenAI接口即可）
- [x] 滚动歌词（B站CC字幕，需要登录；网易云音乐，无需登录）
- [x] 根据歌曲名称+歌手，从网易云音乐获取歌曲ID。通过歌曲ID获取歌词、封面。
- [ ] 收藏夹导入
- [ ] 下载
- [ ] More
